# ⬡ CyberLab

> Interactive cybersecurity training platform for students.

🌐 **Site linki:** [siberlabo.netlify.app](https://siberlabo.netlify.app/)

## Modüller / Modules

| Modül | Açıklama | Zorluk |
|-------|----------|--------|
| 🔓 Brute Force | Parola saldırısı simülasyonu | Başlangıç |
| 🔍 OSINT | Açık kaynak istihbarat | Orta |
| 📡 Nmap | Port tarama & keşif | Orta |
| 🎣 Phishing URL | Sahte bağlantı tespiti | Başlangıç |
| 💉 SQL Injection | Veritabanı enjeksiyon saldırısı | İleri |

## Özellikler / Features

- 🇹🇷 / 🇬🇧 Türkçe & İngilizce dil desteği
- Her modülde teori + interaktif simülasyon
- Gerçek terminal çıktısı simülasyonu
- Saf HTML/CSS/JS — kurulum gerektirmez

## Kullanım / Usage

Sadece `index.html` dosyasını bir tarayıcıda aç.  
Just open `index.html` in any browser.
